# Computer Programming I Midterm Project

## Objective

Create a unique Java program of your own choice that solves a real-life problem or makes a decision based on user input. All students will use the same required Java topics, but the project scenario, inputs, conditions, and output must be different for every student.

## Required Concepts

Your program must use:

* `Scanner`
* Variables and data types
* User input
* `if`
* `else if`
* `else`
* Nested `if`
* Logical operators (`&&`, `||`, etc.)

## Instructions

* Create a Java program based on a real-life situation or problem of your choice.
* Your program must accept information from the user using `Scanner`.
* Use `if`, `else if`, and `else` to make decisions.
* Include at least one nested `if` statement.
* Your program must produce a meaningful result, recommendation, classification, or decision.
* Your project must be different from every other student's project.
* You must create your own conditions and decision-making logic.
* Use clear variable names and organize your code properly.
* Your program must have at least **5 user inputs**.
* Add appropriate messages so the user understands what information to enter.

---

## ⚠️ VERY IMPORTANT: UNIQUE PROJECT

**EVERY STUDENT MUST HAVE A DIFFERENT PROJECT.**

You may choose any topic, as long as it uses the required Java concepts. For example, one student could make a system about:

* Food ordering
* Movie recommendations
* Travel decisions
* Student evaluation
* Shopping discounts
* Salary computation
* Sports eligibility
* Job application
* Game character selection
* Event registration
* Electricity usage
* Loan evaluation
* Pet care
* Restaurant recommendations
* Internet plan selection

*These are only examples. You are NOT limited to these topics.*

> **--- No two students should have the same project concept. ---**

---

## Duplicate Project Policy

If two or more students submit the same or substantially similar project, their work will **NOT** be checked immediately. The student/s will be required to explain and demonstrate their project and code personally.

**You may be asked:**

* What is the purpose of your program?
* What does each variable represent?
* Why did you use `if` here?
* Why did you use `else if`?
* Where is your nested `if`?
* What happens if the user enters a different value?
* How does your program arrive at its final result?
* Why did you choose these conditions?

**If you cannot explain your own code, your project will not be considered complete.**
